# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, insults and
personal attacks aren't tolerated in issues, pull requests or any other project space.

Report conduct problems privately to the maintainer through
[GitHub's advisory form](https://github.com/24samj/react-native-glaze/security/advisories/new) (choose any
category and say it's a conduct report). Reports are kept confidential. The maintainer may remove content
or block participants who break these rules.
